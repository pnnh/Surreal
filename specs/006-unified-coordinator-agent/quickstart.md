# Quickstart: 统一主聊天 Agent 与子 Agent 任务协同架构

**Branch**: `006-unified-coordinator-agent` | **Date**: 2026-11-11

本文档提供开发者与测试者手动验证 **Coordinator-Subagent 协同链路** 的操作指南。

---

## 前置准备

1. 确保环境变量已配置有效 Poe 密钥：
   ```bash
   cp .env.example .env
   # 编辑 .env 填入 POE_API_KEY
   ```
2. 启动本地开发服务：
   ```bash
   pnpm dev
   # 浏览器访问 http://127.0.0.1:3000
   ```

---

## 验证场景 1：通用会话与普通闲聊

1. 点击左上角「新建对话」按钮；
2. 验证：界面不再弹出类型选择框，直接进入通用会话工作区；
3. 输入闲聊内容：“你好，你能为游戏开发者做些什么？”；
4. **预期结果**：
   - 主 Agent 友好介绍生图、位图图标和 SVG 矢量图标能力；
   - 界面**不显示**生成确认卡片或无意义的“尺寸/透明度”反问列表。

---

## 验证场景 2：意图派发与子 Agent 代理拷问 (Grill Relay)

1. 在上述会话中输入：“帮我做一个游戏里的魔法药水图标”；
2. **预期结果**：
   - 主 Agent 识别出“位图图标”诉求，激活 `IconSpecialist` 子任务；
   - 界面展示协同提示（如“图标专家正在细化参数…”）；
   - 回复中包含图标专业反问卡片（例如尺寸 16/32/64、是否需要透明背景、暗黑风还是像素风）；
3. 回复：“16和32尺寸，经典红药水，透明背景”；
4. **预期结果**：
   - 输入精准命中挂起的子任务，子 Agent 确认就绪并触发直出；
   - 界面呈现生成的图标预览（含 16x16 与 32x32 尺寸）；
   - 本地落盘在 `data/assets/<convId>/icons/`。

---

## 验证场景 3：同一会话跨模态生成（SVG 矢量图标）

1. 在刚才已经生成了药水图标的会话中，继续输入：
   “再顺便帮我做一份单色的魔法书 SVG 矢量图标”；
2. **预期结果**：
   - 主 Agent 自动将新任务派发给 `SvgSpecialist`；
   - 反问或直接推导出带有 `currentColor` 与 `viewBox` 的矢量图标；
   - 生成完成后在对话流中展示 SVG 预览；
   - 本地落盘在 `data/assets/<convId>/svg/`。

---

## 验证场景 4：历史独立会话向下兼容性

1. 检查侧边栏历史会话列表；
2. 点击之前在 `specs/004` 或 `specs/005` 创建的独立图标或 SVG 会话；
3. **预期结果**：
   - 正常加载历史消息与图片，无红屏报错；
   - 会话顶部显示对应的类型标签。
